# ska-longctx

Code for *Scalable Kernelized Attention for Long-Context Retrieval* (NeurIPS 2026).

This repository contains the reference implementation of the kernelized attention
layer used in the paper, together with the experiment scripts needed to reproduce
the main results.

## Layout

- `src/` - model and data code
- `experiments/` - training and sweep entry points
- `notebooks/` - analysis notebooks
- `results/` - aggregated numbers reported in the paper
- `tests/` - smoke tests
